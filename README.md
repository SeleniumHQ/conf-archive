# Selenium Conference Archive

This repository hosts static versions of past Selenium and Selenium-related conference websites, including SeleniumConf
and AppiumConf. It serves as a historical archive for the global Selenium community.

🌐 You can browse the archive at: [https://selenium.dev/conf-archive](https://selenium.dev/conf-archive)

## 🗂 What’s Included

Each past edition has its own folder under the `editions/` directory, containing the original website content (cleaned
from the Wayback Machine or other sources).

The homepage links to each edition and includes:

- Event location and dates
- Link to the restored website
- Playlist of talks (if available)
- Event photos (if available)

## 🤝 Contributions

If you have an old edition you’d like to restore or know of additional resources (videos, photos, speaker decks), feel
free to open a pull request or issue.
